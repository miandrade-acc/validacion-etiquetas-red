# 🖼️ Recursos Visuales de la Interfaz (`/app/assets/`)

Esta carpeta contiene capturas de pantalla reales del funcionamiento del bot Telegram desarrollado para la validación automática de etiquetas de red, así como ejemplos de etiquetas procesadas.

## 📸 Capturas del bot en funcionamiento

| Archivo | Descripción |
|--------|-------------|
| `1. Inicio del Bot.jpeg` | Mensaje de bienvenida al iniciar el bot. |
| `2. Bot iniciando proceso.jpeg` | Interfaz al recibir una imagen para análisis. |
| `3. Etiqueta valida.jpeg` | Respuesta cuando la etiqueta procesada es válida. |
| `4. Etiqueta no valida.jpeg` | Respuesta cuando la etiqueta no cumple con los criterios. |
| `5. Despedida del bot.jpeg` | Mensaje de cierre de sesión o despedida del usuario. |

## 🏷️ Ejemplos de etiquetas procesadas

| Archivo | Descripción |
|--------|-------------|
| `6. Etiqueta-RC-VALIDA-01.jpg` | Ejemplo de una etiqueta de Ruta Completa válida. |
| `7. Etiqueta-RC-NO VALIDA-01.jpg` | Ruta Completa no válida. |
| `8. Etiqueta-RNA-VALIDA-01.jpg` | Ruta No Aplica válida. |
| `9. Etiqueta-RNA-NO VALIDA-01.jpg` | Ruta No Aplica no válida. |
